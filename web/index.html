本地标签打印排程台

控制端 :8000 · 两个独立 worker · 本地打印机模拟器（不接真实打印机）

① 提交批次

请求键相同且内容相同 → 返回原批次；内容不同 → 409 冲突。序号唯一，正文为 1~80 个可打印 ASCII 字符。

标签（1～8 张，顺序固定按序号升序）

② 批次与标签状态

批次 ID请求键批次状态 待派发待核对已出纸未出纸 当前 worker / 租约创建时间

③ 打印机故障开关（模拟器）

首次丢响应：指定标签记账后第一次响应丢失（须在该标签出纸前打开），worker 凭操作键找回回执，不会重复出纸。
暂停回执：记账后扣留回执，直到点“释放”，期间 worker 租约可过期并被另一个 worker 接管核对。

④ 打印机出纸账本

账本只追加、不可变；以 <批次ID>-<序号> 为操作键，正文与回执原子记入。

操作键批次序号正文回执 ID记账时间
